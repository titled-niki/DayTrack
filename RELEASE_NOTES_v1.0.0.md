# DayTrack v1.0.0

The first public release of **DayTrack**, a private, local-first activity tracker for Windows.

## Highlights

- Tracks active time per application
- Active / AFK, PC uptime, lock and sleep statistics
- Aggregate keyboard press and mouse click counters
- Aggregate network traffic totals
- Desktop widget and activity dashboard
- Daily TXT reports plus CSV / JSON export
- Local SQLite storage
- Windows autostart and tray controls
- Dark / Light / System themes
- English, Russian, Ukrainian, Japanese, and Simplified Chinese
- Installer and Portable distributions
- No account or DayTrack cloud service required

## Privacy

DayTrack does not store typed text, individual keys, passwords, clipboard contents, mouse coordinates, screenshots, or network packet contents.

## Notes

- Windows x64 only.
- The application is currently unsigned. Windows SmartScreen may show an unknown-publisher warning.
- Application launch counts are sampling-based and may miss very short-lived processes.
- Network traffic is tracked as aggregate adapter totals, not per application.
