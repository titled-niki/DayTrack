DAYTRACK PORTABLE v1.0.0

1. Extract the ZIP completely to a folder.
2. Run DayTrack.exe.
3. Complete the first-run configuration.

PRIVACY
- DayTrack works locally.
- No account or DayTrack cloud service is required.
- The primary database is stored in %LOCALAPPDATA%\DayTrack.
- Daily reports are stored in the location selected by the user.

NOTE
"Portable" means DayTrack can run without installation.
User data is still stored in %LOCALAPPDATA%\DayTrack.
